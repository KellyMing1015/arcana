# 当前牌局的退出保护与恢复

日期：2026-10-06

## 用户行为

- 解读页“重新开始”先询问“要重新抽牌吗？”，提醒只保留“重新开始会结束当前牌局。”，默认焦点在“留下来”。取消、Esc、点击弹窗外都不清空。确认后才结束当前牌局并进入新提问。
- 对话页“结束对话”先确认，提醒只保留“结束后仍可查看。”。只有服务器确认结束后才切换只读；请求失败仍保留开放的对话。
- 普通返回解读页不结束牌局，按钮变为“回到对话”。已结束的牌局仍可通过“查看对话”阅读。
- 回应生成中返回，需要确认暂停；等待当前请求收尾后再切换页面，避免迟到的回应写入下一局。
- 浏览器返回从对话回到解读；再返回首页时先确认重新开始。旧浏览记录不能重新构造已清除的牌局。
- 在同一标签页刷新，恢复牌面、解读、当前对话、草稿与剩余轮数。服务器若已经完成回答，则恢复完整回答；尚未完成的提问可以重试。

## 保存与恢复

使用 `sessionStorage` 保存当前标签页的一局。保存字段采用明确白名单，不包含供应商配置、API Key、隐藏 prompt 或带密钥的请求签名。账号切换时，不显示另一账号的缓存；游客会话同时受浏览器 Cookie 约束。图片超出浏览器容量时优先保存全部文字；未发送图片丢失会提示重新选择，已完成图片可从仍有效的服务器会话恢复。

未登录检查会清除旧账号属性，同时保留经过格式验证的游客会话标记，避免刷新时误清游客恢复身份。图片省略标记只用于已知缓存降级，恢复成功后取回服务器图片与完整答案；恢复旧回复不会清除同文字但另选图片的草稿。

新增 `GET /api/conversation/<id>` 返回服务器确认的追问、轮数、busy 和 closed 状态，不返回初次抽牌指令、隐藏 prompt 或提炼总结。恢复期间暂停发送，避免未核对轮数时重复调用。忙碌时每两秒查询最新状态；网络断线时保留内容并提供“重新连接”，不会自动重新发送问题。

结束由删除服务器会话改为标记 closed，保留只读内容，拒绝新的追问；完成请求的缓存重放仍可读取。回答中的会话不可结束或被清理删除。首次结束仍调度塔罗师便签提炼。

## 明确边界

这次修复覆盖当前标签页内的误返回与刷新，不提供所有旧对话的跨设备历史入口。服务器仍沿用原有六小时闲置期限及容量限制；服务器重启或会话过期后，标签页缓存内容仍可查看，继续追问需要重新抽牌。浏览器彻底关闭、清除站点数据或不支持存储时，不能承诺恢复缓存。

保留现有月蚀风格、14px 聊天气泡、图片加载、个人中心、便签和历史牌阵功能。确认框沿用灰银色与圆角，主按钮为“留下来”，不增加新的整页设计。
